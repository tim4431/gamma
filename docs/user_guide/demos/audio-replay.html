How it works

While you record, Gamma keeps the time you wrote each thing: every pen stroke already carries it, and each note gets a stamp.

Press play and the page keeps pace with the audio. Spotlight fades what you haven't written yet, Reveal hides it, and Static leaves the page as it is.

Tap any stroke or note to hear that moment, from 3 s before. A pause leaves no gap in the audio, so what you wrote while paused plays where the recording resumed.
