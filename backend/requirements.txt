# Text recognition of scanned PDFs (gamma/ocr_engine.py): Tesseract 5.5 and
# Leptonica inside the wheel, no system package; the models are in
# backend/tessdata. Where recognition is on, the check at startup imports it
# (ocr_engine.start_check), so a server whose engine does not start says so
# before anyone asks. No iOS or Android wheel (requirements-mobile.txt
# leaves it out), and the macOS wheels need macOS 15 (Darwin 24): on an
# older macOS the marker skips it, since pip would try to build it and
# fail. The release goes on the right of the comparison: pip works out the
# whole marker on every system, and pip 24.1 to 25.3 read the left side of
# `platform_release >= "24"` as a version, so they crash on Linux, whose
# kernel release is no version ("7.0.0-1020-azure" on GitHub's runners:
# the Docker build). With the release on the right, one that is no version
# is compared as text, which every pip does. A server without it reads no
# text itself: the window that asks reads the pages with tesseract.js
# from the models here (ocr_engine capability "window").
